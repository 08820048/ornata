# 欢迎使用 Ornata

Ornata 是一个安静的写作空间。每篇笔记都是你所选文件夹里的普通 `.md` 文件：可以在访达里打开，用 iCloud 同步，放进 git 管理。不需要账号，也不会上传。

这几篇笔记大约十分钟就能读完，带你认识 Ornata。它们本身就是在 Ornata 里写的普通笔记，你在这里看到的一切都可以自己做出来。随意修改，读完就可以删掉。

> [!tip]
> 最好的学习方式是边读边试。想要一张白纸来练习，打开[练习场](note:练习场.md)。

## 最初五分钟

- [ ] 按 **⌘K**，输入几个字，跳到任意笔记或执行命令
- [ ] 按 **⌘N** 新建一篇笔记
- [ ] 在空行输入 `/`，看看能插入什么
- [ ] 输入 `[[` 链接到另一篇笔记
- [ ] 按 **⌘⇧D** 在浅色和深色之间切换
- [ ] 点一下这个列表里的复选框

## 指南

1. [写作与格式](note:上手指南/写作与格式.md)：边写边排版的 Markdown、表格、提示块、脚注、代码和公式
2. [链接、反链与图谱](note:上手指南/链接、反链与图谱.md)：把笔记连起来
3. [查找与浏览](note:上手指南/查找与浏览.md)：搜索、标签页、分屏、笔记库和专注模式
4. [项目与任务](note:上手指南/项目与任务.md)：由任务行组成的看板，附带一个[示例项目](note:上手指南/示例项目/任务.md)
5. [与 AI agent 协作](note:上手指南/与 AI agent 协作.md)：让 Claude Code、Codex 或 Cursor 读写你的笔记
6. [个性化](note:上手指南/个性化.md)：主题、排版、导出和备份

每次更新后，Ornata 会显示这次改了什么。之后也可以随时再看：按 **⌘K**，输入「更新内容」。
