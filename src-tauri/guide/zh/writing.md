# 写作与格式

Ornata 在你输入时写下 Markdown，并直接显示排版后的样子。磁盘上的文件是普通的 Markdown，任何应用都能打开。

## 边写边排版

| 输入 | 得到 |
| --- | --- |
| `#` `##` `###` 加空格 | 标题 |
| `-` 或 `1.` 加空格 | 列表 |
| `- [ ]` 加空格 | 任务 |
| `>` 加空格 | 引用 |
| 三个反引号（再按回车） | 代码块 |
| `---`（再按回车） | 分割线 |
| `**粗体**` `*斜体*` | **粗体**、*斜体* |

也可以在空行输入 `/`，从菜单里选。想看原始的 Markdown，点笔记顶栏里的源码按钮。

## 任务

- [ ] 待办的任务
- [/] 进行中的任务：在行首输入 `[/]` 和空格
- [x] 已完成的任务
- [-] 已取消的任务：输入 `[-]` 和空格

所有笔记里的任务都汇总在 **⌘K** →「未完成任务」，也会出现在[项目](note:上手指南/项目与任务.md)的看板上。

## 提示块

> [!note]
> 以 `[!note]`、`[!tip]`、`[!important]`、`[!warning]` 或 `[!caution]` 开头的引用会变成提示块。写法和 GitHub、Obsidian 一样。

## 表格

在单元格上点右键，可以增删行列、设置列的对齐。鼠标移到表格上，底边和右边会出现「+」条。

| 水果 | 颜色 | 价格 |
| :--- | :---: | ---: |
| 苹果 | 红 | 1.20 |
| 柠檬 | 黄 | 0.80 |

## 脚注

输入 `/footnote` 添加脚注。[^1] 鼠标停在编号上可以读到内容；按住 ⌘ 点击，在编号和脚注之间跳转。

## 代码和公式

```js
function greet(name) {
  return `你好，${name}`;
}
```

行内公式写在一对美元符号之间，比如 $e^{i\pi} + 1 = 0$；独立的公式写在两对之间：

$$
\sum_{n=1}^{\infty} \frac{1}{n^2} = \frac{\pi^2}{6}
$$

## 图片

粘贴或拖入图片，它会保存在笔记库的 `.ornata/assets` 文件夹里。拖动图片右边缘的拖柄调整大小，双击放大查看。
