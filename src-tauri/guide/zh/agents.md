# 与 AI agent 协作

Claude Code、Codex、Cursor 这类编程 agent 可以通过 MCP 使用你的笔记：搜索、阅读、写入，还能从项目看板上领任务。

## 连接

点状态栏里的插头图标。面板里写着每种 agent 怎么连接，大多只要一行配置。有 agent 连着时，插头会变成绿色。

## 决定它能做什么

「设置 → 智能体」决定 agent 在这个笔记库里能做什么：不允许、只读、读写，或全部。agent 做的每次修改都会留下历史快照，你可以查看，也可以撤销。

## agent 与项目

agent 可以要下一个任务、认领它（卡片上会显示它的 logo）、标记完成、记下它做的决定，这些都只是你 Markdown 里的普通文字。想亲自交给它一个任务，就在看板上右键那张卡片，选「复制给 agent」。
