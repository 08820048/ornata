# Playground

A blank page for trying things. Nothing here matters: type, format, break it, delete it.

Some ideas:

- Type `#` and a space at the start of a line to make a heading
- Type `- [ ]` and a space to start a task, `>` and a space for a quote, three backticks for a code block
- Select a word and press **⌘B** or **⌘I**
- Type `/table` and press Enter
- Press **⌥↑** or **⌥↓** to move the current paragraph up or down

Write below this line.
