# Working with AI agents

Coding agents such as Claude Code, Codex and Cursor can work with your notes through MCP: search them, read them, write them, and pick up tasks from a project board.

## Connect one

Click the plug in the status bar. The panel shows how to connect each agent; most need one line of configuration. The plug turns green while an agent is connected.

## Decide what it may do

Settings → Agents sets what agents may do in this vault: nothing, read only, read and write, or everything. Every change an agent makes keeps a history snapshot, so you can see it and undo it.

## Agents and projects

An agent can ask for the next task, claim it (the card shows its logo), mark it done and write down what it decided, all as plain lines in your Markdown. To hand one over yourself, right-click a task on the board and choose "Copy for an agent".
