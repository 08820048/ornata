# Make it yours

Settings is at **⌘,**.

## Themes

Pick a colour scheme for light mode and another for dark under Appearance; **⌘⇧D** switches between light, dark and following the system. The swatch in the status bar changes it on the spot.

## Typography

Settings → Editor sets the text size, the line width and the line spacing of the page.

## Export

Export a note as PDF, HTML or Markdown, or copy it as rich text, from the menu in the note's header. Page size and margins for PDFs are in Settings → Export.

## Backups

Settings → General → Backup saves a dated zip of the vault to a folder you choose, every day; put it in iCloud Drive or Dropbox and it's off this computer too. To restore, unzip it.

## Your files

Everything is in the folder you picked: notes under `notes/`, pasted images under `.ornata/assets/`. Quit Ornata and the files are still yours.
