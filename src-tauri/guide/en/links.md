# Links, backlinks and the graph

Notes become more useful once they point at each other.

## Linking

Type `[[` and start typing a note's name, or use `/link`. Ornata saves an ordinary Markdown link with the note's path, like `[Playground](Playground.md)`, so links keep working in other apps. Rename or move a note and the links to it are updated.

Click a link to open the note. Rest the pointer on one to see the start of that note without leaving this one. Try it: [Welcome to Ornata](note:Welcome.md).

## Backlinks

At the bottom of a note you'll find the notes that link to it, and notes that mention its name without linking yet, so you can turn a mention into a link with one click.

This guide is linked from [Welcome to Ornata](note:Welcome.md) and from [Writing and formatting](note:Getting started/Writing and formatting.md); scroll down to see them.

## The graph

**⌘K** → "Link graph" draws every note as a dot and every link as a line. Notes in the same folder share a region. Drag dots around, search, and click a note to open it. Each note also has a small graph of its own neighbours at the bottom.

## Tags

Write `#idea` anywhere in a note to tag it. **⌘K** → "Tags" lists them all.
