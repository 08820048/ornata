# Welcome to Ornata

Ornata is a quiet place to write. Every note is a plain `.md` file in the folder you picked: open it in Finder, sync it with iCloud, keep it in git. No account, no upload.

These notes take about ten minutes and show you around. They are ordinary notes, written in Ornata, so everything you see here is something you can make yourself. Edit them, and delete them once you're done.

> [!tip]
> The best way to learn is to try things as you read. For a blank page to experiment on, open [Playground](note:Playground.md).

## Your first five minutes

- [ ] Press **⌘K** and type a few letters to jump to any note or run a command
- [ ] Press **⌘N** to make a new note
- [ ] Type `/` on an empty line to see what you can insert
- [ ] Type `[[` to link to another note
- [ ] Press **⌘⇧D** to switch between light and dark
- [ ] Click a checkbox on this list

## The guides

1. [Writing and formatting](note:Getting started/Writing and formatting.md): Markdown as you type, tables, callouts, footnotes, code and math
2. [Links, backlinks and the graph](note:Getting started/Links, backlinks and the graph.md): connecting notes
3. [Find your way around](note:Getting started/Find your way around.md): search, tabs, split view, the library and focus mode
4. [Projects and tasks](note:Getting started/Projects and tasks.md): a board made of task lines, with [an example project](note:Getting started/Example project/Tasks.md)
5. [Working with AI agents](note:Getting started/Working with AI agents.md): let Claude Code, Codex or Cursor read and write your notes
6. [Make it yours](note:Getting started/Make it yours.md): themes, typography, export and backups

After each update, Ornata shows what changed. You can open it again any time: **⌘K**, then "What's new".
