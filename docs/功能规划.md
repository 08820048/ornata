### 10.17 命令行与 MCP（对标 Thymer 的 thymercli）
> 调整：访问级别（关闭 / 只读 / 读写 / 完全访问）存在应用配置里，在设置页按笔记库选择，默认只读；命令行参数只能降低、不能提高——否则智能体能改自己的 MCP 配置给自己提权（对照 Thymer 的 MCP Settings：访问级别在应用里选）。
> 目标：让任何外部智能体（Claude Code、Codex、Cursor、Gemini CLI…）不依赖应用界面就能操作笔记库。决定：stdio 方式的 MCP（无端口、无网络暴露）+ 常用命令行；同一个可执行文件，带参数运行时进入命令行模式；默认只读，`--write` 开放写入，`--allow-destructive` 开放重命名 / 移动 / 删除；复用 agent_tools 里现成的带权限、带历史快照的笔记操作。
